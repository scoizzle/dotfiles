# Memory

Bookshelf. Read this file before heavy work. Open a file below only when its blurb matches the task.

## The ladder

- `learnings/pending/` — untrusted, staged. Written by `dream`; agents do not read it.
- `learnings/` — the dated archive, tracked, reachable once a person promotes.
- `core/` — curated, edit-denied, portable: the workflow invariants that hold on every machine.

A line climbs only when a person moves it. `dream --promote` moves pending into the
dated archive; consolidating the archive into `core/` is a human edit, not an
automated step.

## What travels, and where it lives

The working copy is `~/.config/opencode/memory`, a sparse clone of this
repository provisioned by `install.cs`, not a link to a checkout. Dated
`learnings/YYYY-MM-DD.md` files are tracked, so a clone elsewhere gets them after a
merge. `pending/` is tracked only on the `memory/dream` staging branch, and
`working.md` is local, rebuilt by `dream --promote` on each machine.
`bin/memory-nightly` publishes the staged lines to `memory/dream` as a draft PR;
promotion and consolidation stay with a person.

## Core

Agents do not edit these files. Core holds workflow invariants — permissions,
safety, how work is cut — not model IDs or harness quirks, which change per machine
and belong in a dated learning tagged `[harness]`.

- `core/conventions.md` — Where tiers, evidence, and C# / Roslynk live, in a few lines. The full workflow stays in `AGENTS.md`.
- `core/safety.md` — What stays off limits, and undo cost for ship-versus-ask. Reinforces Safety in `AGENTS.md`.

## Learnings

Agents may append dated files here. Lessons are constraints, not transcripts.

- `learnings/README.md` — Version header (who, when UTC, session or context id, source) and the `never` / `known` / `derived` lines, each tagged `harness`, `loop`, or `graph`.
- `learnings/pending/YYYY-MM-DD.md` — Staged by `dream`, not yet reviewed. Agents do not read these; a person runs `dream --promote`.
- `learnings/working.md` — Generated by `dream --promote` from the dated files: duplicates collapsed, each line citing its sources. Read this first when it exists; open any dated file it does not name in its `source:` line. Agents do not write it.
- `learnings/YYYY-MM-DD.md` — The archive. Constraint lines from earlier sessions, tracked so they travel with the clone. Read the newest of these when the task could repeat a past failure, a bad command, or a wrong path.
