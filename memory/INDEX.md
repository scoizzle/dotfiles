# Memory

Bookshelf. Read this file before heavy work. Open a file below only when its blurb matches the task.

## Core

Agents do not edit these files.

- `core/conventions.md` — Where tiers, evidence, and C# / Roslynk live, in a few lines. The full workflow stays in `AGENTS.md`.
- `core/safety.md` — What stays off limits, and undo cost for ship-versus-ask. Reinforces Safety in `AGENTS.md`.

## Learnings

Agents may append dated files here. Lessons are constraints, not transcripts.

- `learnings/README.md` — Version header (who, when UTC, session or context id, source) and the `never` / `known` / `derived` lines, each tagged `harness`, `loop`, or `graph`.
- `learnings/pending/YYYY-MM-DD.md` — Staged by `dream`, not yet reviewed. Agents do not read these; a person runs `dream --promote`.
- `learnings/working.md` — Generated by `dream --promote` from the dated files: duplicates collapsed, each line citing its sources. Read this first when it exists; open any dated file it does not name in its `source:` line. Agents do not write it.
- `learnings/YYYY-MM-DD.md` — The archive. Local constraint lines from earlier sessions. Read the newest of these when the task could repeat a past failure, a bad command, or a wrong path.
